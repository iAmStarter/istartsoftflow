# PLAN-0005 — Bounded autonomous workflow
> Revision: 2

## Approved scope

Implement the user's approved autonomous workflow plan against main: routine
choices within approved scope, bounded test/fix/retry, independent work despite
blocked tasks, durable checkpoint/resume, acceptance criteria and current-revision
evidence, truthful completion, and capability-specific Claude/Codex/Cursor support.

- Add an explicit local task state helper with dependencies, attempt/unit budgets,
  validated transitions, persistence, and evidence requirements. It is not an agent
  executor or a scheduler and cannot grant approval.
- Align quick/feature/phase/goal/sprint procedures and methodology. Preserve
  approval and risk boundaries; do not turn task blockers into global stops.
- Integrate checkpoint discovery and installer packaging. Document exact host
  capabilities, fallbacks and verification limits.
- Add runtime/contract/installer regression tests and rebuild generated templates.
- Publication modes none/push/push+pr require matching explicit user authorization.
  Initial delivery was local only. The subsequent user instruction authorizes
  pushing this verified implementation directly to main; no PR or deployment.

## Acceptance criteria

1. Independent runnable tasks continue when another task is blocked; dependencies
   never bypass a blocked prerequisite. Budgets and attempts remain bounded.
2. Restart preserves task state, counters and evidence; stale updates and malformed
   state fail clearly instead of discarding progress.
3. Completion requires evidence tied to the attempt and reported code revision;
   documentation distinguishes caller attestation from actually executed checks.
4. All three target adapters install a usable helper in CommonJS and ESM projects;
   absent native features are described honestly and have explicit fallbacks.
5. Applicable local tests, template synchronization, approval scope and package
   checks run against final files; live host and remote CI gaps are disclosed.
