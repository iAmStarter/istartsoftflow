# PLAN-0009 — Show verified npm version in website footer
> Revision: 1

## Scope
Add a bilingual footer near copyright distinguishing the documented package target
from the npm registry's latest published version. Read latest from the official
registry on page load, use safe text rendering, a timeout and an honest unavailable
fallback. No npm package changes or token/OTP changes. Test and deploy via the same
repository PR/check/merge route authorized for this release.

## Acceptance
Registry response determines npm version; docs version never substitutes for it.
Offline/no-JS/invalid response remains unverified with a direct npm link. Tests pass
and GitHub Pages serves updated HTML and JavaScript.
